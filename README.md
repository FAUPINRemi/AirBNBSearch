# AirBNBSearch
Projet scolaire : Système de recherche d'annonce airbnb avec critère
Stack : ExpressJS, EJS, MongoDB, Mongoose


# LANCER L'APP
 
Après avoir clone le repo il faut faire un "npm install" pour télécharger les dépendanses
puis démarer le contenuer docker avec "docker compose up --build". 

(Ne pas oublier de définir le port et l'uri mongo db dans un .env)
